# مقدمة إلى ASP.NET MVC من خلال أمثلة (نوفمبر 2013)

يحتوي هذا المستودع على النسخة **HTML** من الوثيقة *مقدمة إلى ASP.NET MVC من خلال أمثلة*، التي نُشرت في الأصل في **نوفمبر 2013**.
